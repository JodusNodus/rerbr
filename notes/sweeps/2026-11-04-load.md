# Load sweep, 2026-11-04

`scripts/sweep-load.py`: every RallySimFans stage folder and every BTB stage, started as the launcher's Start does
(`rerbr --command`, every graphics option on, grass included, no texture upscaler), offscreen at 1280x720 with the
autopilot, `--no-sound` and force feedback off, a picture at drive frame 1500; the script groups the stderr lines that
look like problems and checks each picture (missing, black, one colour). Outputs: `$RBR_RUNS/sweep-load-2026-11-04/`
(the full run on the build before the fixes) and `$RBR_RUNS/sweep-load-2026-11-04-recheck/` (the fixed stages and
controls on this branch); not in git.

## What ran

558 runs, 3 at a time, Toyota GR Yaris Rally2 (RSF 107): 437 RSF stage folders, 78 BTB stages, and 43 runs of every
12th stage meant for a retail car. Those 43 asked for Peugeot 206 99, which an RSF install does not list, so the
launcher started the Alpine A110 RGT instead; the script now refuses a swapped car. No run timed out.

launcher test failures (`local_codriver_packs_drive_without_rsf`, `the_first_start_opens_on_what_needs_attention`:
"No NGP.dll found") fail on main too, in this environment. The recheck of 325-328, 432 and 562, plus Livadija,
Gabiria, Fintele and two BTB stages as controls: all ok.
